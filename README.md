# LucaPhylo


LucaPhylo is an alignment-free phylogenetic inference framework powered by hyperbolic protein language models.

**The complete source code will be available shortly**


## Installation

1. Create a virtual environment.

```bash
conda create -n lucaphylo python=3.10.16
```

2. Activate the environment.

```bash
conda activate lucaphylo
```

3. Clone the repository.

```bash
git clone https://github.com/NickShannn/LucaPhylo.git
cd LucaPhylo
```

4. Install dependencies.

```bash
pip install -r requirements.txt
```
